Documentation / Memento

Memento is the dashboard interface of FDO MoMEnT. It provides a comprehensive view of your created FDOs, displays FAIR score statistics, and offers administrative overview capabilities.

Overview

The Memento interface uses a sidebar navigation pattern, allowing you to switch between different views: Statistics, Your FDOs, All FDOs (admin), and Admin Overview.

Page Descriptions

The Memento dashboard consists of several views accessible through the sidebar navigation:

1. Statistics

Overview of your FDO statistics and FAIR score metrics.

  • Total FDOs — Number of created digital objects
  • Overall Score — Average FAIR score across all FDOs
  • FAIR Breakdown — Individual scores for Findable, Accessible, Interoperable, Reusable

2. Your FDOs

A paginated table view of all your created FDOs.

  • Sortable columns — Sort by ORCID, Research Domain, FAIR Score, Creation Date
  • Pagination — Navigate through pages of results
  • Quick view — See key metrics at a glance

3. All FDOs (Admin)

A comprehensive view of FDOs across all users (admin only).

  • User column — Shows the owner of each FDO
  • Research Domain — Displays research domain information
  • Full sorting — Sort by any column

4. Admin Overview

System-wide statistics and user activity overview (admin only).

  • Total Users — Number of registered users
  • FDOs per User — List of users with their FDO counts and average scores
  • System Health — Overview of platform usage
