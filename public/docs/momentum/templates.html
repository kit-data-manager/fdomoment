Documentation / Momentum / Templates

Templates provide pre-configured starting points for creating FDOs. You may choose a template based on which kind of digital object you want to represent by a FAIR Digital Object. The template selection gives you a short description on the template, its purpose, and lists contained modules.



For each template there are mandatory modules that cannot be changed. These modules are marked with a 🔒. Modules that are not marked can be enabled (default) or disabled by clicking them, e.g., if you do not want to or can provide publication information for a data object.


To select a template, just click the box outside the module badges. You will be directed to a confirmation page showing you the entire template description and a list of enabled modules. From this page you can either go back to change your selection or proceed with creating the FAIR Digital Object. You may now proceed to the → Modules documentation


💡 Before you finally select a template and start filling it in be sure, that you can provide all information required in the selected modules (see → Modules documentation). Most modules only contain mandatory fields and if you cannot fill them with convenient values, you may have to start over again with the template selection losing the previous progress.
